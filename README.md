# Engenharia_de_Prompt_Aplicacoes_AI
Este repositório reúne experimentos, projetos, aplicações e boas práticas em Inteligência Artificial e Engenharia de Prompt.
O objetivo é explorar, documentar e compartilhar formas eficientes de usar modelos de IA para resolver problemas reais.
Aqui você encontrará desde prompts estruturados até aplicações completas integrando IA em sistemas, APIs e automações.
